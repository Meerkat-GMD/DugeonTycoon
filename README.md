# 던전 타이쿤

플레이어는 사회자로서 던전을 배치하고 실시간으로 개입합니다. 탱커, 힐러, 근거리 딜러, 원거리 딜러로 구성된 AI 파티는 조우를 극복하며 마왕전에 대비합니다.

## 첫 원정 플레이

1. Unity에서 [SampleScene](Assets/Scenes/SampleScene.unity)을 열고 **Play**를 누릅니다.
2. 고블린이나 오우거를 고른 뒤 던전 바닥을 클릭합니다. 한 칸에 여러 마리를 둘 수 있고, **한 마리 되돌리기**로 클릭한 칸의 몬스터를 하나씩 되돌리면 예산도 돌아옵니다. 입구 주변의 주황색 테두리 안에는 둘 수 없습니다. 오른쪽이나 가운데 버튼으로 드래그하면 화면이 움직이고, 휠로 확대·축소합니다. 첫 판은 고블린 네 마리를 놓아 볼 수 있습니다.
3. 출발하면 파티가 보스방을 찾아 던전을 탐색합니다. 아직 보지 못한 곳은 어둡게 덮여 있습니다. 갈림길에서는 용사들이 성격대로 의견을 내고, 의견이 갈리면 d20 + 매력으로 설득 판정을 해서 길을 정합니다. 몬스터는 자기 자리 주변을 돌아다니다가 용사를 발견하면 쫓아오고, 전투는 실시간으로 벌어집니다. 탱커와 근딜은 적에게 붙고, 원딜과 힐러는 거리를 두며, 탱커는 도발로 적의 공격을 받아냅니다. 보스와 싸우기 시작하면 보스방 입구가 닫힙니다. 카메라는 파티를 따라가고, 드래그하거나 아래 줄의 버튼을 누르면 따라가기를 끕니다. 낙석 역경을 선언하면 용사의 대응 대사와 d20 판정이 표시됩니다. 다친 용사가 있으면 신앙을 써서 회복시킬 수 있습니다.
4. 성문 수호자를 이긴 뒤 두 번째 던전에 몬스터를 배치하고 다시 출발하면 마왕 벨자크에 도전합니다.

API 키 없이도 로컬 전술 AI로 플레이할 수 있습니다. [OpenAI 연동 방법](tools.md#openai-용사-판단)을 참고하세요.

## 개발 시작

- [개발 도구와 실행법](tools.md)에서 환경 점검, Unity 프로젝트 열기, Core 테스트 명령을 확인할 수 있습니다.
- [게임 규칙](gamerules.md)에는 두 스테이지의 진행 방식, 주사위 판정, 첫 플레이 검증 기준이 있습니다.
- [작업 규칙](AGENTS.md)에는 코드와 에셋을 수정할 때 지킬 기준과 변경 종류별 검증 방법이 있습니다.

## 코드 구성

| 위치 | 책임 |
| --- | --- |
| `Assets/Game/Core` | 순수 C# 게임 규칙. `DungeonTycoon.Core.asmdef`는 엔진 참조를 끕니다. |
| `Assets/Game/Unity` | 씬과 게임 규칙의 연결. `DungeonTycoon.Unity.asmdef`가 Core와 UniTask를 참조합니다. Unity에서 비동기 작업은 UniTask로 처리합니다. |
| `DotNet` | Unity와 같은 Core 소스를 컴파일하는 .NET 프로젝트와 독립 테스트. |
